\section*{Approved C-LPSD bridge}
For a selected uninterrupted segment of $N$ samples at rate $f_s$, the diagnostic
one-cycle frequency is $f_{1/T}=f_s/N$. The C feasibility lower limit is
\begin{equation} f_{\min}^{\rm C}=\frac{\mathrm{SBIN}}{T}
\left[1+(1-O/100)(m-1)\right],\qquad f_{\max}<f_s/2,\qquad
J_{\rm des}=\left\lceil\frac{\log(N/2)}{\log(1+1/Q)}\right\rceil,\quad Q=10^6.\end{equation}
The C executable is invoked in LPSD mode with Kaiser window $-w\,-2$, PSLL
200 dB, 50\% overlap, linear-regression detrending ($-r\,1$), desired averages
100, and minimum averages 1. It reports a one-sided PSD $S_x(f)$ directly;
the bridge applies no scale beyond $-x\,1$ and defines $\mathrm{ASD}_x=\sqrt{S_x}$.
For the approved $m=1$, $f_{\min}^{\rm C}=\mathrm{SBIN}/T$. SBIN is queried
from the actual configured C executable, never hard-coded. This is a window
feasibility limit, not a data-quality cut. For input unit $U$, $[S_x]=U^2/\mathrm{Hz}$ and $[\mathrm{ASD}_x]=U/\sqrt{\mathrm{Hz}}$.

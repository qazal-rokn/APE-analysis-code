\section*{Approved reduced-block APE cleaning}

The synchronized raw channels are partitioned into non-overlapping 0.05 s
records with midpoint times $t_k$.

For the cavity channel,
\begin{equation}
\bar V_k = \operatorname{mean}(V_{\rm trans}),
\qquad
V_{\min,k}=\min(V_{\rm trans}).
\end{equation}
The centered 60 s cavity reference is
\begin{equation}
V_{{\rm ref},k}
=
Q_{0.90}\left(
\{\bar V_j: |t_j-t_k|\le30\,{\rm s}\}
\right),
\end{equation}
with cavity decision
\begin{equation}
M_{{\rm cav},k}
=
\left[V_{\min,k}\ge0.90V_{{\rm ref},k}\right].
\end{equation}
The cavity reference is recomputed from provisionally good blocks three times.

For each raw sample,
\begin{equation}
I_0[n]=C_{\rm trans}V_{\rm trans}[n],
\qquad
R_{2f}[n]=\sqrt{X_{2f}[n]^2+Y_{2f}[n]^2},
\end{equation}
\begin{equation}
\eta_0[n]
=
\sqrt{
\frac{2\sqrt{2}\,R_{2f}[n]}
{H_2qGI_0[n]}
}.
\end{equation}
For each 0.05 s block,
\begin{equation}
\bar\eta_{0,k}
=
\operatorname{mean}(\eta_0[n])_{n\in k},
\qquad
\eta_{0,\min,k}
=
\min(\eta_0[n])_{n\in k}.
\end{equation}

Within a cavity-good segment, the protected eta0 reference is
\begin{equation}
\eta_{{\rm ref},k}
=
Q_{0.90}\left(
\left\{
\bar\eta_{0,j}:
t_k-60\,{\rm s}\le t_j<t_k,\
M_{\eta,j}=1
\right\}
\right),
\end{equation}
and
\begin{equation}
M_{\eta,k}
=
\left[
\eta_{0,\min,k}\ge0.80\eta_{{\rm ref},k}
\right].
\end{equation}
Rejected eta0 blocks do not update the reference. If no accepted block remains
inside the preceding 60 s during a sustained eta0 failure, the last valid
healthy reference is held.

At the beginning of every cavity-good segment, eta0 reference state is reset
and the first valid eta0 block mean bootstraps the reference. A file boundary
does not reset the reference when the cavity-good segment continues across
declared-continuous files.

The final block decision is
\begin{equation}
M_{{\rm final},k}=M_{{\rm cav},k}\land M_{\eta,k}.
\end{equation}

\section*{Approved efficient longest-segment search}

The full acquisition is first processed with cavity cleaning only.
Cavity-good intervals are ranked by duration. Sample-level eta0 is evaluated
only for candidate intervals that can still exceed the best surviving
final-good interval.

Candidates are processed longest-first. Evaluation stops when
\begin{equation}
T_{\rm best}\ge T_{\rm cavity,next},
\end{equation}
because eta0 cleaning can only shorten an unprocessed cavity-good interval.

\section*{Approved APE raw-to-calibrated chunk conversion}

The recorded demodulated quadratures are treated as RMS voltages. For each
validated raw sample,
\begin{equation}
I_0 = C_{\mathrm{trans}} V_{\mathrm{trans}},
\end{equation}
\begin{equation}
R_{2f}=\sqrt{X_{2f}^2+Y_{2f}^2},
\end{equation}
\begin{equation}
\eta_0 =
\sqrt{
\frac{2\sqrt{2}\,R_{2f}}
{H_2 q G I_0}
},
\end{equation}
\begin{equation}
\rho_X =
\frac{X_{1f}}
{\sqrt{2}\,qGI_0\eta_0},
\qquad
\rho_Y =
\frac{Y_{1f}}
{\sqrt{2}\,qGI_0\eta_0}.
\end{equation}
Here $H_2$ is the measured photodiode/electronics response at $2f$.
The science quadratures remain separate. Invalid physical samples preserve
their original indices and calibrated outputs are set to NaN. This stage
performs no smoothing, filtering, interpolation, resampling, clipping, phase
correction, gain-imbalance correction, leakage correction, or X/Y combination.

\section*{Approved C-LPSD bridge}
For a selected uninterrupted segment of $N$ samples at rate $f_s$, the
diagnostic one-cycle frequency is $f_{1/T}=f_s/N$. The C feasibility lower
limit is
\begin{equation}
f_{\min}^{\rm C}=\frac{\mathrm{SBIN}}{T}
\left[1+(1-O/100)(m-1)\right],
\qquad
f_{\max}<f_s/2,
\qquad
J_{\rm des}=\left\lceil
\frac{\log(N/2)}{\log(1+1/Q)}
\right\rceil,
\quad Q=10^6.
\end{equation}
The C executable is invoked in LPSD mode with Kaiser window $-w\,-2$, PSLL
200 dB, 50\% overlap, linear-regression detrending ($-r\,1$), desired averages
100, and minimum averages 1. It reports a one-sided PSD $S_x(f)$ directly; the
bridge applies no scale beyond $-x\,1$ and defines
$\mathrm{ASD}_x=\sqrt{S_x}$. For the approved $m=1$,
$f_{\min}^{\rm C}=\mathrm{SBIN}/T$. SBIN is queried from the actual
configured C executable, never hard-coded. This is a window feasibility limit,
not a data-quality cut. For input unit $U$, $[S_x]=U^2/\mathrm{Hz}$ and
$[\mathrm{ASD}_x]=U/\sqrt{\mathrm{Hz}}$.

\section*{Legacy calibrated quadrature review}
The older review-only path uses a frozen reference denominator
\begin{equation}
D[n]=\sqrt{2}\,I_0[p(n)]\,\eta_0[p(n)]\,R\,G,
\qquad
X_{\rm ell}[n]=X_V[n]/D[n],
\qquad
Y_{\rm ell}[n]=Y_V[n]/D[n].
\end{equation}
This legacy path is retained for historical cross-checks and is not the
authoritative implementation of the new raw-to-calibrated streaming stage.
